# Fit-Life-Fitness-TRACKING-WebApp

FitLife is a fitness tracking web application developed using React and Vite.

## Features

* User-friendly fitness dashboard
* Workout plans
* Nutrition tracking
* Water intake tracking
* Calorie tracking
* Progress tracking
* Beginner-friendly workout recommendations
* Responsive web interface

## Technologies Used

* React
* Vite
* HTML
* CSS
* JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/Amarapriyanjith/Fit-Life-Fitness-TRACKING-WebApp.git
```

Go to the project folder:

```bash
cd Fit-Life-Fitness-TRACKING-WebApp
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Project

FitLife was developed as a university group project to provide users with an accessible platform for managing workouts, nutrition, water intake, calories, and fitness progress.
